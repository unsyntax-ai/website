CredNation (Now Doberme)

About the Project

Building and scaling a two-sided security marketplace from MVP to full production.

Designed and engineered a full two-sided marketplace MVP

  • Guard onboarding, verification & licensing workflows
  • Job posting and real-time matching
  • Guard availability and scheduling logic
  • Client dashboards and job management tools
  • Secure authentication and role-based access
  • Clean, reliable backend built for speed and future expansion
  • Modular architecture ensuring rapid iteration without technical debt

Launched the MVP quickly and positioned for funding

  • Delivered stable, investor-ready MVP fast enough for demo and early user onboarding
  • Founders secured funding at $12M valuation within one month of launch
  • Validated both product and execution approach

Expanded platform into full production system

  • Rebranded to Doberme
  • Took platform from MVP to robust, scalable V2
  • Implemented new UI/UX from design team
  • Improved match logic and job flow
  • Enhanced stability, speed, and reliability
  • Added features for guard and client operations
  • Hardened infrastructure for real-world usage
  • Modernized internal workflows for better UX

Delivered smooth rebrand transition

  • Seamless migration from CredNation to Doberme
  • Identity updates and platform adjustments
  • Rollout planning and user transition
  • Technical alignment with new brand vision

The Challenge

The founders needed a complete tech foundation built from scratch with two different user types requiring different workflows.

No existing tech foundation - entire platform had to be designed, architected, and engineered from scratch
Two different user types requiring different workflows - guards needed onboarding, verification, scheduling; clients needed booking and management
Had to be investor-ready MVP yet stable and scalable for long-term growth
Any delay risked investor confidence and market entry timing

Impact & Results

Clear product-market validation - MVP helped secure significant early valuation and fueled investor confidence
Stable, scalable V2 - production build handled complex two-sided workflows without performance issues
Professional-grade user experience - updated UI combined with improved flows created polished, trustworthy platform
Faster operations - workflows previously manual became automated, improving efficiency
Strong technical foundation for growth - architecture supports new features and future expansion
Smooth rebrand rollout - transition happened without downtime or user friction
Fully functional, high-stability marketplace capable of scaling across states
